# Contributing

Read the complete [universal constitution](https://gist.github.com/vex-graph/4132a6c45cb6d3797c3e8eff2e94035a)
(workspace `../../preferences.md`), then [local preferences](primeagen-preferences.md),
`../../tests/test-preferences.md`, current checklist and actual sources.

Tests belong to the independent workspace `tests/primeagen` checkout, never
production source. Strict native builds retain assertions and use C23 with
`-Wall -Wextra -Werror`. Live calls/credentials and GUI approval are not implied
by offline tests. Document, verify and commit locally; never push without a
one-off instruction. Cite laws by Title.
